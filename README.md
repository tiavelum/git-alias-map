# git-alias-map

A tool for keeping the git aliases of a `gitconfig` small and understandable: it shows which alias calls which, down to the git command each chain ends in, and lets them be reduced in a browser page. The repository holds the tool only, no alias data.

## Getting started

The repository holds no tool yet. Read [issue #1](https://github.com/tiavelum/git-alias-map/issues/1) first: it states the command that writes the editor page and what the page does.
